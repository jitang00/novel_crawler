# 📚 万能小说爬虫 v3.4

通用中文小说下载器，支持大部分小说网站。自动识别章节目录、智能提取正文，导出为干净的 TXT 文件。

## ✨ 功能特性

- **自动识别章节目录** — 支持 ul/li、dl/dt/dd 等多种目录结构，智能区分"最新章节"和"全部章节"
- **智能正文提取** — 链接密度算法过滤导航/侧边栏，自动移除广告、推荐、版权声明等噪音
- **多线程并发爬取** — 10 线程同时下载，自动按序拼接，速度提升显著
- **章节内分页跟随** — 一章分多页时自动拼接完整内容（最多 50 子页）
- **正序/倒序自动检测** — 通过 URL 数字趋势和标题数字双重判断，确保章节顺序正确
- **目录分页支持** — 自动检测并加载多页目录（catalog/d_1.html 等格式）
- **JavaScript 链接解析** — 支持 gobook、readbook 等 JS 跳转格式的章节链接
- **反爬适配** — 支持 C0NTENT 等用数字替代字母的反爬 class 名
- **自动编码检测** — 从 HTML meta charset 正确识别 GBK/GB2312/UTF-8 编码
- **断点可控** — Ctrl+C 安全中断，等待进行中的任务完成后退出

## 🚀 快速开始

### 方式一：直接运行 Python 脚本

```bash
# 安装依赖
pip install requests lxml

# 运行
python novel_crawler.py
```

### 方式二：打包为 EXE（推荐分发）

```bash
pip install pyinstaller
pyinstaller --onefile --console --name 小说爬虫 novel_crawler.py
```

生成的 EXE 可以双击运行，无需 Python 环境。

## 📖 使用方法

1. 运行程序（双击 EXE 或 `python novel_crawler.py`）
2. 粘贴小说的**目录页** URL（不是某一章的链接）
3. 确认章节数量，输入 `y` 开始爬取
4. 等待完成，TXT 文件自动保存到脚本所在目录

## ⚙️ 配置项

在脚本顶部可调整以下参数：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `MIN_DELAY` | 0.3 | 请求最小间隔（秒） |
| `MAX_DELAY` | 1.5 | 请求最大间隔（秒） |
| `MAX_RETRIES` | 3 | 单个请求最大重试次数 |
| `TIMEOUT` | 20 | 请求超时时间（秒） |
| `MAX_WORKERS` | 10 | 并发线程数 |

## 🔧 依赖

- Python 3.7+
- [requests](https://pypi.org/project/requests/) — HTTP 请求
- [lxml](https://pypi.org/project/lxml/) — HTML 解析

```bash
pip install requests lxml
```

## 📋 已适配网站类型

- 笔趣阁系列站点
- 起点/纵横/晋江等主流小说网
- 各类使用 ul/li 或 dl/dt/dd 目录结构的小说站
- JavaScript 跳转链接的站点
- 目录分页的站点
- 章节正文分多页的站点

## ⚠️ 注意事项

- 请仅用于个人学习研究，请勿用于商业用途
- 请尊重原创作者版权，支持正版阅读
- 部分网站可能需要 JavaScript 渲染（如 SPA 站点），本工具暂不支持
- 建议适当调整 `MIN_DELAY`/`MAX_DELAY`，避免对目标站点造成过大压力
