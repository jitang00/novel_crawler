# 📚 万能小说爬虫 v3.5

一个轻量、智能的中文小说下载工具，支持绝大多数小说网站。  
自动识别章节目录、提取正文内容、处理分页章节，并导出为干净的 **TXT** 文件。

> ⚠ **本程序仅供学习交流使用，请勿用于任何商业或非法用途。**  
> 下载内容请遵守目标网站的 `robots.txt` 及用户协议，合理控制并发，尊重版权。

---

## ✨ 功能特点

- 🧠 **智能目录识别** – 自动检测“全部章节”、“正文”区域，支持多页目录及 `javascript:` 链接
- 📖 **自动正文提取** – 基于文本密度与链接密度分析，过滤广告、导航、标签等噪音
- 🔗 **分页章节合并** – 一章分为多页时，自动跟随“下一页”链接并拼接完整内容
- ⚡ **多线程并发** – 可自定义线程数（1~50），显著提升下载速度
- 🔄 **正序/倒序自适应** – 通过 URL 数字或标题数字自动判断目录顺序，无需手动调整
- 📁 **纯文本输出** – 导出为 UTF-8 编码的 TXT 文件，章节标题清晰分隔
- 🛡️ **反爬友好** – 内置随机延迟、请求重试、伪装 User-Agent，降低被封锁风险

- 依赖库：`requests`, `lxml`
