# 📚 万能小说爬虫 v3.5

一个轻量、智能的专门为中文小说优化的下载工具，支持绝大多数小说网站。  
自动识别章节目录、提取正文内容、处理分页章节，并导出为干净的 **TXT** 文件。

> ⚠ **本程序仅供学习交流使用，请勿用于任何商业或非法用途。**  
> 下载内容请遵守目标网站的 `robots.txt` 及用户协议，合理控制并发，尊重版权。
Sites publish fiction under their own terms and copyright. This tool is meant for personal use only, for example keeping a backup of material you already have access to, where the licence allows it. Do not use it to redistribute or sell someone else's work. You are responsible for how you use Lightnovel Crawler.

## ✨ 功能特点

- 🧠 **智能目录识别** – 自动检测“全部章节”、“正文”区域，支持多页目录及 `javascript:` 链接
- 📖 **自动正文提取** – 基于文本密度与链接密度分析，过滤广告、导航、标签等噪音
- 🔗 **分页章节合并** – 一章分为多页时，自动跟随“下一页”链接并拼接完整内容
- ⚡ **多线程并发** – 可自定义线程数（1~50），显著提升下载速度
- 🔄 **正序/倒序自适应** – 通过 URL 数字或标题数字自动判断目录顺序，无需手动调整
- 📁 **纯文本输出** – 导出为 UTF-8 编码的 TXT 文件，章节标题清晰分隔
- 🛡️ **反爬友好** – 内置随机延迟、请求重试、伪装 User-Agent，降低被封锁风险

```bash
pip install requests lxml
```

> 如需打包成独立 EXE，可使用 `pyinstaller -F novel_crawler_V3.5.py`。

## 🚀 使用方法

1. **运行脚本**  
   ```bash
   python novel_crawler_V3.5.py
   ```

2. **输入目录页 URL**  
   粘贴小说网站的**章节目录页**地址（例如 `https://www.example.com/book/123/`），按回车。

3. **选择线程数**  
   - 保守（5~6）：适合小站或敏感网站  
   - 平衡（8~12）：推荐，速度与安全兼顾  
   - 激进（15~20）：速度快但可能触发反爬  
   - 直接回车：使用默认值 10 线程

4. **确认下载**  
   输入 `y` 开始爬取，进度条实时显示完成百分比和失败数量。

5. **获取文件**  
   爬取完成后，TXT 文件会保存在脚本同目录下（若为 EXE 则保存在 EXE 所在目录）。

## ⚙️ 高级配置（可选）

你可以编辑脚本开头的配置常量：

| 变量名             | 说明                             | 默认值 |
| ----------------- | -------------------------------- | ------ |
| `MIN_DELAY`       | 请求最小间隔（秒）               | 0.3    |
| `MAX_DELAY`       | 请求最大间隔（秒）               | 1.5    |
| `MAX_RETRIES`     | 单次请求最大重试次数             | 3      |
| `TIMEOUT`         | 请求超时（秒）                   | 20     |
| `MAX_WORKERS`     | 默认线程数                       | 10     |
| `OUTPUT_DIR`      | 输出目录（自动识别 EXE 环境）     | 脚本所在目录 |

## 🧠 工作原理简析

1. **目录解析**  
   - 分析目标页面的链接结构，通过正则、路径特征、父容器分组筛选出章节链接。  
   - 检测“最新章节”与“全部章节”区域，优先使用完整列表。  
   - 支持多页目录（例如 `catalog/d_2.html`）和 `javascript:` 跳转链接。

2. **正文提取**  
   - 通过常见 CSS / XPath 选择器定位正文容器，并使用**链接密度**过滤侧边栏、推荐列表等噪音。  
   - 逐行过滤广告关键词、短标签、纯标点行，保留干净的段落文本。

3. **分页合并**  
   - 在章节页面内查找“下一页”链接，若该链接**不是**目录中的其他章节，则视为子页，继续追加内容。

4. **多线程调度**  
   - 使用 `ThreadPoolExecutor` 并发请求，按原始索引顺序重组最终内容，避免错乱。
